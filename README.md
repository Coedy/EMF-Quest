# EMF-Quest
A Tildagon choose your own adventure built with Tildagen and tweaked with Claude.


Created using [Tildagen](https://github.com/webboggles/tildagen) then tweaked with [Claude](https://claude.ai/) for easier display when I added more paths/options.

**Important Disclaimer:** _EMF Quest_ is based on "real" events, legendary locations, and actual robots from EMFCamp. However, specific dialogues, exaggerated plot twists, and potential camp-wide doomsday scenarios have been fictionalised for your gaming entertainment.

**If you think anything should be removed or added feel free to do a pull request.**

This could also be a fun base for other Choose Your Own games.
